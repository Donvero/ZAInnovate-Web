## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm or pnpm

### 1. Clone the repository
```bash
git clone https://github.com/Donvero/ZAInnovate-Web.git
cd ZAInnovate-Web
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
```bash
cp .env.example .env
```

### 4. Run automated test suites
```bash
npx vitest run
```
Expected output: **7/7 tests passed (100%)** covering API validation, status codes, and security headers.

### 5. Build for production
```bash
npm run build
```
Compiles with static route optimization and strict type validation.
